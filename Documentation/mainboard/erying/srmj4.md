# Erying SRMJ4 (i9-13900H)

This page describes how to run coreboot on the Erying SRMJ4 motherboard (13th Gen
Intel Core i9-13900H).

## Required proprietary blobs

```{eval-rst}
+-----------------+---------------------------------+---------------------+
| Binary file     | Apply                           | Required / Optional |
+=================+=================================+=====================+
| FSP-M, FSP-S    | Intel Firmware Support Package  | Required            |
+-----------------+---------------------------------+---------------------+
| Microcode       | CPU microcode                   | Required            |
+-----------------+---------------------------------+---------------------+
| IFD             | Intel Flash Descriptor          | Required (see below)|
+-----------------+---------------------------------+---------------------+
| ME              | Intel Management Engine         | Required (see below)|
+-----------------+---------------------------------+---------------------+
```

IFD and ME are required when flashing the full image; they can be skipped when
flashing only the BIOS region.

## Flashing coreboot

### Internally

The vendor firmware does not lock flash regions. Using [flashrom] or [flashprog]
with `iomem=relaxed` on Linux, you can:
- Flash coreboot from stock firmware
- Flash stock firmware from coreboot
- Update coreboot without opening the case

For BIOS region only:
`flashrom -p internal --ifd -i bios -w ./build/coreboot.rom`

### Externally

SPI chip: W25Q128.V in SOIC-8 package, soldered. Voltage: 3.3V.

## Build

```bash
cp configs/config.erying_srmj4.defconfig .config && make olddefconfig && make
```

## Functionality

### Tested and working

- Memory: 2× 48 GB DDR5 (5600 MT/s), SPD 0x50/0x52
- Serial console: UART A at 0x3f8, IRQ 4
- Super I/O: NCT6796D (NCT6791D driver), HWM at 0x0a20/0x0a40
- Fan control: Smart Fan IV via devicetree (SYSFAN, CPUFAN, PECI CPU temp)
- HDA: Realtek ALC897 (verb table from runtime dump)
- Display: DDI A/B (HDMI, DP; A=HDMI, B=DP per protectli/topton convention)
- PCIe: pcie4_0 (00:06.0) → M.2 NVMe; RP5 (1c.0) → M.2 NVMe; RP10 → RTL8125
- Intel I219-V GbE
- VBT: extracted from vendor firmware
- Flash layout: BIOS 0x558000–0xffffff; default.fmd matches vendor IFD

### Unverified

- USB port map
- HDA plug test (jack-to-pin mapping)
- DDI A/B physical assignment (confirm by plug test)
- PCIe clk_src/clk_req

### Not present on board

- PS/2 keyboard/mouse (KBC disabled)
- Second UART (UART B disabled)

## Super I/O and fan control

The bootblock programs only superiotool "diffs" (registers where vendor ≠ POR).
Generated by `util/gather_board_data/superiotool_dump_to_bootblock.py` from
`srmj4_board_data.json`. HWM (LDN 0x0b) is excluded; devicetree configures it.

To regenerate the bootblock C block:
```bash
python3 util/gather_board_data/superiotool_dump_to_bootblock.py -x 0x0b
```
`-x 0x0b` excludes HWM; fan/PECI are configured via devicetree chip registers.

Fan curves (FAN1 SYSFAN, FAN2 CPUFAN) use Smart Fan IV with PECI CPU temp.
Edit `register "FAN1.*"` / `"FAN2.*"` in devicetree.cb to adjust. The OS can
override via `sensors` / `fancontrol` (nct6775 driver).

## Developer notes

### Board data sources

Verified from `srmj4_board_data.json`, inteltool, superiotool:
- Memory, HDA, SIO, GPIO (intelp2m), GPE routing, PCIe, eSPI decode, VBT, IFD

### GPIO

`gpio.h` built from `inteltool -g`, `intelp2m -platform adl -f cb -iiii`, then
`intelp2m_iiii_to_short_macros`.

### HDA verb table

Produced via runtime dump (vendor BIOS + Linux `init_pin_configs` + hda-decoder).
To re-extract: boot vendor BIOS, run `hda-decoder -generate` on live codec state.
See `util/hda-decoder`.

### DDI / VBT

Parse VBT: `intel_vbt_decode --file src/mainboard/erying/srmj4/data.vbt`

Board has 1 DP + 1 HDMI. Devicetree enables DDI A and B; A=HDMI, B=DP assumed.
Confirm by plug test; swap A/B in devicetree if reversed.

### Flash layout

`default.fmd` matches vendor IFD (ifdtool). BIOS region 0x558000–0xffffff
(0xaa8000). CBFS_SIZE 0xa98000.
